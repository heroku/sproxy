# Contributing to sproxy

## Governance Model

sproxy is published but not supported. It is open sourced because it may contain
useful or interesting code and concepts to share with the larger open source
community. Occasional work may be done on the project, but the maintainers do
not solicit contributions or provide support commitments.

## Issues and Pull Requests

You may use [GitHub Issues](https://github.com/heroku/sproxy/issues) to report
public bugs or share ideas. Pull requests are reviewed at the maintainers'
discretion and may not receive a response.

If you submit a pull request:

1. Base it on the `master` branch.
2. Keep the change focused and include relevant tests when practical.
3. Ensure the applicable test suite passes before submitting.
4. Sign the Salesforce Contributor License Agreement when prompted.

## Contributor License Agreement

To accept a pull request, Salesforce requires a Contributor License Agreement
(CLA). You only need to complete it once for Salesforce open source projects.
Complete the CLA at [cla.salesforce.com/sign-cla](https://cla.salesforce.com/sign-cla).
